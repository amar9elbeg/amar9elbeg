# 💫 About Me

I build software that ships. Currently at **Pinecone Studio**, where I spend most of my time on the parts of a codebase nobody puts in a demo — the test suites, the monorepo wiring, and the pipelines that turn a merge into a deploy.

Five years in, my focus has narrowed to one question: **how do you keep a growing codebase fast to change?** That means strict typing, tests that actually catch things, module boundaries that hold, and CI that fails loudly and early.

- 🌟 Working at **Pinecone Studio**
- 💼 **5 years** of professional experience
- 🛠️ Specialized in **testing**, **monorepos**, and **CI/CD pipelines**
- ⚡ Day to day: TypeScript, React, Next.js, GraphQL, Nx
- 🧪 Believer in tests that describe behavior, not implementation
- 🚀 Always learning — the stack changes, the fundamentals don't
